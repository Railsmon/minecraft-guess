# ⛏️ Minecraft 猜猜乐

一个以 Minecraft 为主题的网页猜物品小游戏！

通过输入物品名称来猜测系统随机选择的 Minecraft 物品。根据每次猜测获得属性提示，逐步缩小范围，最终找出正确答案。

## ✨ 游戏特色

- **海量物品数据库**：收录 Minecraft 中的多种方块、物品及其他内容。
- **属性对比**：通过分类、维度、版本、用途等信息判断答案。
- **智能提示**：根据猜测结果提供属性反馈。
- **得分系统**：猜测次数越少，获得的分数越高。
- **个人最高纪录**：记录浏览器本地保存的最高得分。
- **物品资料**：猜中答案后可以查看相关物品信息。
- **原版风格图标**：尽可能使用 Minecraft 原版资源。
- **背景音乐**：支持选择本地音乐文件、播放、暂停、音量调节和循环播放。
- **苦力怕主题界面**：采用 Minecraft 风格的像素化 UI。

## 🕹️ 游戏玩法

1. 打开游戏，点击「开始游戏」。
2. 系统随机选择一个 Minecraft 物品作为答案。
3. 在输入框中输入物品名称。
4. 从自动补全列表中选择物品，或提交输入内容。
5. 根据属性反馈继续猜测。
6. 猜中答案后获得本局分数。

### 🏆 计分规则

| 猜测次数 | 获得分数 |
|---|---:|
| 1 次 | 1000 分 |
| 2 次 | 900 分 |
| 3 次 | 800 分 |
| 4 次 | 700 分 |
| 5 次 | 600 分 |
| 6 次 | 500 分 |
| 7 次及以上 | 最低 100 分 |

放弃本局则获得 0 分。

## 🚀 本地运行

本项目是一个静态网页项目，无需安装额外的运行环境。

1. 下载或克隆本仓库。
2. 找到 `index.html`。
3. 使用浏览器打开即可游玩。

## 🌐 网站部署

本项目支持使用 GitHub Pages 部署：

1. 将游戏文件上传到 GitHub 仓库。
2. 确保主页文件名为 `index.html`。
3. 进入仓库的 `Settings`。
4. 找到 `Pages`。
5. 选择 `Deploy from a branch`。
6. 选择 `main` 分支和 `/ (root)` 目录。
7. 保存并等待部署完成。
